## 一、当天在十天计划中的位置

Day 1–Day 9 已完成定位、项目深挖、技术题库、算法基础、AI 全栈补齐和三轮模拟。Day 10 的目标不是再记更多名词，而是完成三件事：

1. **选对材料**：根据 JD 只拿出最相关的项目和题库，不把所有经历平均铺开。
2. **说对事实**：统一项目名称、职责、技术栈、指标和边界，避免不同天数材料在口述时互相矛盾。
3. **按面试执行**：准备开场、项目卡、白板题、反问和答不出时的兜底，形成可在面试前快速复习的固定路径。

## 二、当天能力目标

完成后，你应当能够：

- 在 10 分钟内根据一份真实 JD 选出项目讲述顺序、必答题和 2–3 个反问。
- 以“背景与问题 → 目标与约束 → 方案 → 决策 → 本人职责 → 难点 → 验证 → 风险改进”完整讲一个项目。
- 分别完成 1 分钟、3 分钟、5 分钟的自我介绍/项目组合口述，并能根据 Agent、RAG、AI 全栈、模型研究四类岗位切换。
- 在共享屏幕或白板场景下，清楚写出至少三类算法模板和三张工程图的关键不变量。
- 面试中遇到未做过的消息队列、WebSocket、K8s、高并发、LLM 微调/RL 等话题时，准确说明已有基础、方案思路和经验边界。

## 三、最终执行原则

### 1. 先匹配岗位，再选择项目

- **Agent / AI Coding 岗**：AI Coding Harness → 成果评审 Agent → 质量管理体系 Agent → 论文引用查证。
- **RAG / AI 应用岗**：论文引用查证 → 质量管理体系 Agent → 成果评审 Agent。
- **AI 全栈岗**：Agent 项目 → FastAPI / 数据库工程化 → 轻舟 Vue3 / 旧全栈经历。
- **模型研究 / 训练岗**：红外动作识别 → LLM / Transformer 基础 → Agent 应用项目；明确 LLM 微调、强化学习和训练框架不是已确认既有项目经验。

### 2. 先给结论，再给证据与边界

每个回答使用固定骨架：

> **结论**：我会/我选择……。**依据**：在……项目中，我负责/参与……，通过……解决……。**边界**：当前已确认……；……需要以代码或记录核对，不能把它说成既有事实。

### 3. 答不出不猜测

> 这个具体实现参数我现在不能确认，不想凭记忆补全。它要解决的是……；结合我已确认的项目事实，我做的是……。如果继续排查，我会先看……，再通过……验证。当前风险是……。

## 五、核心事实边界

- 当前简历为 `resume/个人简历2.0.pdf`；项目事实以其为准。
- 质量管理体系 Agent：结构化指标由指标引擎计算，质量体系 checklist 由 RAG 提供依据，LLM 做受控归纳；Edge 使用 SQLite Outbox、游标增量、批次幂等和多实例隔离。
- 成果评审 Agent：9 节点 LangGraph、路径/行号/快照 SHA 证据链、证据索引校验、无证据降级、状态机、幂等创建、取消/重试和审计记录均为确认事实。
- AI Coding Harness：工程上下文与人工审批闭环是核心；不说它替代了人工负责、自动上线或与成果评审 Agent 是同一个项目。
- 论文引用查证：确认 Hybrid RAG、人工标注集、Recall@k、证据覆盖率、判定准确率和证据不足降级；没有确认的具体分数不补充。
- 轻舟是 Vue3 / Vue Router / Vuex / Axios / ECharts / Ant Design Vue；React 条件轮询只是独立企业平台工程补充。轻舟已确认周期刷新，未确认 WebSocket。
- 红外课题确认 NTU RGB-D、Cross-Subject、ResNet-18 + LSTM、两层红外增强、Uniform Sampling、轻量 Temporal Attention；96.55% Accuracy / 0.9934 AUC 与 0.9424 F1 来自不同配置和指标，不能直接比较。
