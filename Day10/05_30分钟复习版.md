# Day 10：30 分钟复习版——最终面试执行包

> **唯一目标**：在面试前快速拉起最匹配的主线和事实边界。此时不刷新题、不扩展知识，只做选择、口述和风险扫雷。

---

## 0–5 分钟：选岗位主线

- **Agent / AI Coding**：Harness → 成果评审 → 质量 Agent。
- **RAG / AI 应用**：论文引用查证 → 质量 Agent → 成果评审。
- **AI 全栈**：Agent 工程 → FastAPI/状态/幂等 → 轻舟 Vue3。
- **模型研究**：红外动作识别 → 理论基础 → Agent 工程；明确微调/RL 边界。

**动作**：从目标岗位选一条线，60 秒口述。不要把四条线全部背一遍。

## 5–12 分钟：四个项目的一句话

1. **质量管理体系 Agent**：指标工具算事实，RAG 给规范依据，LLM 归纳；Edge 用 Outbox、游标、批次幂等接入内网数据。
2. **成果评审 Agent**：9 节点工作流把 checklist、快照、事实、路径/行号/SHA 证据和裁决串起来；无证据降级人工确认。
3. **AI Coding Harness**：把任务、决策、接口契约、测试计划沉淀为工程上下文，AI 编码后人审验收，不自动越权。
4. **论文引用查证**：GROBID 解析 + BM25/FAISS/Rerank + 人工标注评测；证据不足返回无法确认。

## 12–18 分钟：六个必答题

1. **为什么不能让 LLM 直接算业务指标？**
   - 确定性事实交给指标引擎/受控工具，LLM 负责归纳解释。
2. **如何降低评审 Agent 幻觉？**
   - 证据绑定路径、行号、快照 SHA；校验证据索引；无证据降级。
3. **Edge 同步怎么保证可靠？**
   - Outbox 记待发，游标增量，批次幂等吸收重试重复；不是恰好一次。
4. **长任务如何可靠？**
   - 幂等创建、状态持久化、超时/有界并发、协作式取消、重启中断标记和审计。
5. **Hybrid RAG 为什么有用？**
   - BM25 补术语，向量补语义，Rerank 提升排序；用评测集定位问题。
6. **轮询和 WebSocket 怎么选？**
   - 看实时性和复杂度；轻舟确认周期刷新，不说已有 WebSocket。

## 18–23 分钟：算法与白板

```text
哈希：先查后放，避免复用同一元素。
滑窗：窗口状态始终有效，左右指针单向移动。
二分：先定义边界语义，利用单调性收缩区间。

评审：checklist → 快照 → 事实 → 证据 → 裁决 → 无法确认/人工确认
同步：GitLab → Edge → 游标 → Outbox → 批次 → 中心幂等
长任务：防重 → 幂等创建 → 后台执行 → 状态 → 轮询/提示
```

每个模板说出：**不变量 + 边界 + 复杂度/风险**。

## 23–27 分钟：事实边界扫雷

- 轻舟是 **Vue3**；React 条件轮询是独立工程补充。
- 评审任务确认后台线程，不说消息队列、WebSocket、K8s 或高并发压测已落地。
- 论文项目没有确认的评测分数、Redis key/TTL、线上规模不补。
- 红外指标来自不同配置与指标，不直接比较数值；不编超参数或硬件。
- 团队成果、个人职责、通用方案必须分开说。
