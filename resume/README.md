# 简历版本与事实来源

## 当前简历

`个人简历2.0.pdf`

## 使用规则

1. 每次生成、更新或检查面试材料前，先读取本文件，再读取“当前简历”标记的 PDF。
2. 若 `resume/` 中出现版本号更高的 `个人简历X.Y.pdf`，以更高版本为准，并同步把本文件的“当前简历”改为该文件。
3. 用户明确说“这是最新简历”或“以此为当前简历”时，即使版本号较低也以用户指定为准，并更新本文件；仅临时指定某份旧简历时，只在当次任务使用，不改动当前简历。
4. 文件名无法按版本号比较、同一版本存在多个候选，或 PDF 缺失时，不猜测事实来源；在后续学习材料中说明并请用户确认。
5. 原始 PDF 含个人信息，默认被本目录的 `.gitignore` 排除。Markdown 学习材料应只记录项目事实，不复制联系方式。

## 更新简历后的同步范围

先核对新版简历与旧版的项目名称、职责、技术栈、时间和指标，再更新受影响的 Day1 定位、自我介绍、行为题、JD 关键词表，以及后续对应项目卡。没有出现在新版简历或用户补充信息中的事实，不保留为既有经历。
