### 当前代码可核验的工程补充

- `agent_research/frontend` 是独立的 **React 18 + TypeScript + Vite + React Query + Axios + Ant Design + ECharts** 产品研发平台，不是简历中轻舟 Vue3 项目的代码。
- 代码评审页面对活动任务采用条件轮询：存在活动状态时每 3 秒刷新；有任务创建、取消、人工确认、下载报告与加载失败提示等交互。
- 可用于说明“我理解前端如何与长任务状态联调”，但不能说这是轻舟项目的技术栈或功能。

### 红外动作识别课题事实

- 面向卫星货舱等封闭、复杂光照环境的物资管理需求，完成基于红外视频的动作触发识别方法，为后续多模态感知提供稳定触发信号。
- 基于 NTU RGB-D，采用 ResNet-18 + LSTM 的非 Transformer 基线，完成数据划分、训练和评估流程设计。
- 设计两层红外增强、Uniform Sampling 与轻量 Temporal Attention。
- 官方 Cross-Subject 协议下：均匀采样方案达到 **96.55% Accuracy、0.9934 AUC**；综合配置达到 **0.9424 F1**。
- 论文《融合时序采样与轻量时间注意力的红外动作触发识别方法》已录用至《计算机应用研究》，第一作者。
