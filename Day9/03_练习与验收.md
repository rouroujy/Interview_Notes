## 二、全真模拟规则

1. 找同学扮演面试官最好；独自练习时，用随机数或遮住参考落点抽题。
2. 第一次作答全程不看材料，不跳题；每题先结论，后依据，最后边界。
3. 允许面试官从任意回答中连续追问一次“为什么”“替代方案”“你具体做了什么”“如何验证”。
4. 计时结束前不暂停查资料；不知道就使用四句兜底，不编造。
5. 录音只用于复盘：检查是否有无效铺垫、术语堆砌、职责扩大、句子过长和重复口头禅。

## 三、三张白板抽查图

### 1. 证据驱动评审流程

```text
checklist → 仓库快照(SHA) → 目录/依赖解析 → 事实提取
                                         ↓
路径/行号/证据索引 ← 证据组装 ← 逐项裁决 ← LLM
                                         ↓
      合法证据？──否→ 无法确认 ──→ 人工确认/归档
```

**必须说出**：快照保证评审对象稳定；证据索引校验约束 LLM；“无法确认”是风险降级，不是强行给结论。

### 2. Edge 增量同步流程

```text
分公司 GitLab → Edge 读取 → 游标确定增量 → SQLite Outbox
                                             ↓
中心幂等接收 ← 批次重试 ← 网络发送 ← 待发批次持久化
```

**必须说出**：Edge 主动同步适配中心不能访问内网；Outbox 防止“读到了但没记住要发”；游标防全量，幂等吸收重复。

### 3. 前端长任务联调流程

```text
用户操作 → 前端防重 → 创建接口 + 幂等键 → 后台任务
   ↑                 ↓                         ↓
异常提示 ← 轮询/推送读取状态 ← 状态持久化/阶段/错误码
```

**必须说出**：HTTP 不等待长任务完成；前端状态与用户编辑冲突时暂停/恢复刷新；当前项目未确认 WebSocket 或消息队列实现。

## 四、口述复盘检查表

每轮录音结束后逐项打勾：

- [ ] 每题前 15 秒内给出了直接结论。
- [ ] 至少一次明确说出真实项目名，而不是泛讲概念。
- [ ] 项目职责使用“我负责 / 我参与 / 团队完成”之一准确归属。
- [ ] 说到指标时，能说明指标来源、实验配置或“未确认具体值”。
- [ ] 说到选型时，能给出替代方案和不选择它的原因。
- [ ] 不会时给出排查路径，而没有猜测细节。
- [ ] 未把 Vue3 轻舟与 React 企业平台、轮询与 WebSocket、后台线程与消息队列混为一谈。

## 五、最小修复卡

```text
10 分钟后再次口述分数：/10
```
